# Atari VCS — HTML / CSS / JS Fundamentals Project

A five-page promotional site built for the HTML, CSS & JavaScript Fundamentals course at Georgian College (Fall 2025). The theme is a retro marketing site for the Atari Video Computer System (Atari 2600).

## Live Site

https://riokajin.github.io/HTML-CSS-JS-Fundamentals-Adam-Evans/project-1/

## Pages

- **Promotion** — product intro and call-to-action
- **About** — product details and popular games
- **Feedback** — client-side form with simulated submission
- **Support** — FAQ accordion and troubleshooting tips
- **Company** — corporate info and image credits

## Stack

- HTML5 (semantic structure)
- CSS3 (custom properties, gradients, animations, responsive media queries)
- Vanilla JavaScript (no frameworks)
- Normalize.css for cross-browser consistency

## Features

- Accessible FAQ accordion with `aria-expanded` / `aria-hidden` state
- Feedback form with client-side confirmation message
- Responsive layout (mobile, tablet, desktop)
- Retro-inspired visual design using Google Fonts (Orbitron, Press Start 2P, VT323)

## Notes

- The "Order Now" button is a joke — it opens a music video. This is a class project with no e-commerce backend.
- The feedback form has no server component; submission is simulated on the client side.
